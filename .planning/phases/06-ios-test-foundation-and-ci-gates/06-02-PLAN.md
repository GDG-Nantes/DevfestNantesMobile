enum FilterType: String, Codable { case bookmark, complexity, language, room, type }
struct SessionFilter: Codable, Hashable, Equatable { let type: FilterType; let value: String }

```swift
func getDate(date: String) -> Date {
    let newFormatter = ISO8601DateFormatter()
    return newFormatter.date(from: date) ?? Date() // replace Date String
}
```
Start-date strings in fixtures look like "2025-10-16T09:00:00+02:00" or "2025-10-16T07:00:00Z" (both equal Date(timeIntervalSince1970: 1760598000)). Verified with the default-option formatter: both parse to 1760598000; "2025-10-16T09:00:00.000+02:00", "" and "not a date" return nil (fallback to Date()).
