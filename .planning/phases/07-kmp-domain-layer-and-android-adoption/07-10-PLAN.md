- **Classification in the agenda row**: `AgendaViewModel` gets `classifySession: ClassifySessionUseCase` as a fifth constructor parameter and exposes `fun isTalk(session: Session): Boolean`; `Agenda` passes `viewModel::isTalk` through `AgendaLayout(isTalk: (Session) -> Boolean)`, `AgendaPager`, `AgendaColumn` to `AgendaRow(isTalk: Boolean)` (the innermost overload replaces `session.type?.isService() == false` with `isTalk`; the outer overloads and the previews pass it through). Synchronous, so composition timing is unchanged.
- **Navigation**: `MainActivity` gets `private val classifySession: ClassifySessionUseCase by inject()` (MainActivity is on the DI gate's permanent locator allowlist) and `onSessionClick` navigates `if (classifySession.isNavigable(session))`, keeping `analyticsService.eventSessionOpened(session.id)` for every click.
- **Speakers**: `SpeakersViewModel(store, performanceMonitoring, speakerIndex: SpeakerIndexUseCase)` (resolved by the existing `viewModelOf(::SpeakersViewModel)`), `fun firstLetterIndexes(speakers: List<Speaker>): Map<Char, Int>` = `speakerIndex.firstIndexes(speakers).filter { it.letter.isNotEmpty() }.associate { it.letter.lowercase().first() to it.index }` (insertion order kept). The composable that holds the ViewModel computes `remember(speakers) { viewModel.firstLetterIndexes(speakers) }` and `SpeakersListWithScroller` takes the map as a parameter instead of computing it.
- **Venue**: `VenueViewModel(store, venueLanguage: VenueLanguageUseCase)`, `ConfigurationCompat.getLocales(...)[0]?.let { locale -> emit(store.getVenue(venueLanguage.languageFor(locale.language))) }` (null locale still emits nothing).
- **Instrumentation smoke tests** of speakers and venue load `domainModule` next to their feature module (mechanical module-list edit) because the ViewModels now take a domain use case.
