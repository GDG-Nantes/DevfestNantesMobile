- **UI (D-02, D-08)**: `AgendaPager`/`Agenda` take `List<DaySchedule>` (page `n` shows the day with `dayIndex == n + 1`; tab names from `date` as before; `todayPageIndex` keeps its logic over the list). `AgendaColumn(slots: List<TimeSlot>, onSessionClick)`; an internal `formatSlotTime(start: Instant): String` holds the v1.0 label code (`DateFormat.getTimeInstance(SHORT, locale)`, `TimeZone.getDefault()`); when the system locale is null it renders no slot, as v1.0 dropped every session in that case. `currentStartTimeIndex(slots: List<TimeSlot>, now: Instant)` picks the end date of the first session by `room?.name` (v1.0 took the first of the name-sorted group) so the scroll index is identical.
- **Test edits allowed** (Open Question 1 rule, stated in every acceptance list): imports, type renames (`FakeSessionFiltersService` -> `FakeSessionFiltersStore` from `:core:testing`, `SessionFiltersService` -> `SessionFiltersStore`), constructor wiring, selector helpers (`days.value.first { it.dayIndex == day }.slots.flatMap { it.sessions }`), `Map`-built groups -> `TimeSlot` lists in `CurrentStartTimeIndexTest`, Koin module lists.
