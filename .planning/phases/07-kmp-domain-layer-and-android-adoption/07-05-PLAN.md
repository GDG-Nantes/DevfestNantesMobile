## Discretion decisions taken in this plan

- **Golden support lives in `:core:testing`** (commonMain + `androidMain`/`jvmMain`/`iosMain` actuals), so the Android feature tests here and the `:core:domain` tests on JVM and iOS simulator (07-12, 07-13) read and compare the same files with the same code. Root directory: system property `devfest.domainTestdata` on JVM/Android, environment variable `DOMAIN_TESTDATA` on iOS (07-12 passes it with the `SIMCTL_CHILD_` prefix, RESEARCH Pitfall 1).
- **Tests drive the v1.0 `AgendaViewModel` itself** (with `FakeDevFestNantesStore(sessions = snapshot)`, `FakeBookmarksStore`, `FakeSessionFiltersService`, `NoOpPerformanceMonitoring`, `MainDispatcherRule`), then apply `groupSessionsByStartTime` and the LazyColumn re-sort `sortedBy { it.room?.sortIndex }` exactly as `AgendaColumn` does. This pins the real pipeline, HashSet included.
- **Tie canonicalization** (README golden rules): v1.0 order among equal sort keys is unspecified (HashSet iteration, and `Enum.hashCode` differs between JVM runs), so goldens order ties by id and tests compare canonicalized output; the (sortIndex, name) order itself is asserted separately.
- **Time zones / locales**: `Europe/Paris` + `fr-FR` and `Pacific/Auckland` + `en-US` (Auckland moves late sessions past local midnight; RESEARCH A6). Follow `core/ui/src/test/.../DateUtilsCharacterizationTest.kt` for saving/restoring `TimeZone`/`Locale`; set the Robolectric configuration locale with `RuntimeEnvironment.setQualifiers` because `groupSessionsByStartTime` reads `Resources.getSystem().configuration`.
- **Navigable classification on Android** lives in the private `MainActivity.onSessionClick`; it cannot be characterized without refactoring an Activity, so it is pinned by the explicit table of `ClassifySessionUseCaseTest` (07-01) and switched in 07-17 with an identical branch set.
- **"Unchanged" for every v1.0 test of the phase** (D-18, RESEARCH Open Question 1 resolved): no expected value, key literal, JSON literal or ordering assertion is edited; only imports, type renames, constructor wiring and selector helpers change. These characterization tests follow the same rule in later plans.
