## Discretion decisions taken in this plan

- **No new app source file**: the static functions are added inside the existing Swift types, so only the test target gets new `project.pbxproj` entries (the project lists every file explicitly, RESEARCH Pitfall 7).
- **Static API (extracted in 07-07, behavior-preserving, D-10)**:
  - `AgendaViewModel.makeSections(from sessions: [Session], timeZone: TimeZone) -> [AgendaContent.Section]` = today's `sessionsChanged` grouping (`Dictionary(grouping:)` by `parseDate`, sorted keys, `.sorted { $0.room < $1.room }`, day label from a `DateFormatter` with `dateFormat = "yyyy-MM-d"` and `timeZone = timeZone`). `sessionsChanged` calls it with `TimeZone.current` (a `DateFormatter`'s default zone is the current zone, so the output is identical) and keeps setting `isLoading`/`agendaContent`.
  - `AgendaView.sections(_ sections: [AgendaContent.Section], forDay day: String) -> [AgendaContent.Section]` (the `contains(day)` filter), `AgendaView.filteredSessions(_ sessions: [AgendaContent.Session], filters: Set<SessionFilter>, favorites: [String]) -> [AgendaContent.Session]` (body of `getFilteredSessions` followed by the favorites step of `filteredSessionsForSection`), `AgendaView.isNavigable(_ sessionType: SessionType?) -> Bool`. The instance methods and `agendaRow` call them with `viewModel.sessionFilters` / `viewModel.favorites`.
  - `SpeakersViewModel.alphabet(of speakers: [Speaker]) -> [String]` and `SpeakersViewModel.speakers(_ speakers: [Speaker], startingWith letter: String) -> [Speaker]`; `getAlphabets()` and `speakers(for:)` delegate with `speakersContent ?? []`.
  - `VenueViewModel.contentLanguage(forLanguageCode code: String?) -> ContentLanguage`; `currentLanguage` delegates with `Locale.current.languageCode`.
- **Goldens** follow core/domain/testdata/agenda/README.md: `dayIndex` 1/2, `date` = the tab id (`2025-10-16`, `2025-10-17`), slot `start` = `ISO8601DateFormatter().string(from: section.date)` (UTC, `Z`), slot ids canonicalized by (room name or empty string, id) because Swift `sort` does not guarantee stability among equal room names. Swift writes them with `JSONEncoder` `[.prettyPrinted, .sortedKeys, .withoutEscapingSlashes]`; consumers parse JSON (no byte-level cross-writer comparison).
- **Golden record mode**: absent file -> write it and `Issue.record("golden recorded, re-run: <path>")`; present -> exact string comparison. Same rule as the Kotlin `GoldenFiles`.
- **Time zones**: `Europe/Paris` and `Pacific/Auckland` (`TimeZone(identifier:)`); in Auckland late day-1 sessions move to the 2025-10-17 tab and late day-2 sessions fall on 2025-10-18, which no tab shows: this is today's behavior and is pinned as is.
