## Discretion decisions taken in this plan (CONTEXT "Claude's Discretion")

- Package layout: `com.gdgnantes.devfest.core.domain.agenda` (agenda policies and models), `.speakers`, `.venue` (later plans), `.di` (Koin). The namespace `com.gdgnantes.devfest.core.domain` is derived by the convention plugin (`moduleNamespace()`).
- `ClassifySessionUseCase` takes a `Session` (not a `SessionType?`) and exposes three named methods (D-03): `isService(session)`, `isTalk(session)`, `isNavigable(session)`. `isTalk` is the exact Android star condition `session.type?.isService() == false` and the iOS `isATalk`.
- No public extension function or property on exported model types (`Session`, `Room`, `Speaker`...) anywhere in `:core:domain`: Kotlin/Native exports them as members of the model's Swift type and `swift-names-gate.sh check` would fail with SWIFT-MEMBERS-CHANGED (Phase 3 lesson, `RoomSortIndex.kt`). Behavior lives in use-case classes only.
- Swift-names baselines are NOT regenerated here (AGENTS.md: only in the commit that updates matching Swift call sites); new header names are informational in `check`. Plan 07-04 regenerates them with its Swift call sites, plan 07-05 with the `SessionFilter` export (D-13).
