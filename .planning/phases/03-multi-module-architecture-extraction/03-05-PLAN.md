## Resource ownership rule (D-17, applied here and in 03-06..03-08)

For each resource (string/color/dimen name, drawable/mipmap file), the consumer set = modules (per the map above) whose Kotlin references `R.<type>.<name>` or whose XML/manifest references `@<type>/<name>`. App-only (incl. app name, launcher icons `ic_launcher*`, `theme_splash.xml`, `themes.xml`, `locales_config.xml`) -> stays in :androidApp. Exactly one feature -> moves with that feature in its plan. Referenced by a :core:ui file or by 2+ modules -> :core:ui (this plan). No consumer -> stays in :androidApp. values / values-fr / values-night entries of one name always move together; values are never edited.
