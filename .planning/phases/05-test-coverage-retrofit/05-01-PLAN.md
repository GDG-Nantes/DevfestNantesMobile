   - `summary <report.xml>` prints:
     - `TOTAL LINE <covered>/<total> <pct>%`, then the same line for INSTRUCTION and BRANCH. These come from the `counter` elements that are direct children of the root `report` element (JaCoCo format, `missed` + `covered` attributes).
     - Then one `MODULE <gradle-path> LINE <covered>/<total> <pct>%` line per production module, sorted by path. Each module sums the LINE counters of the `package` elements whose slash-separated `name` equals or starts with (followed by `/`) its prefix. The prefix map is:
       - `com/gdgnantes/devfest/androidapp` → `:androidApp`
       - `com/gdgnantes/devfest/shared` → `:shared`
       - `com/gdgnantes/devfest/core/model|network|analytics|data|ui` → the matching `:core:*` path
       - `com/gdgnantes/devfest/feature/venue|about|settings|speakers|agenda|sessiondetail` → the matching `:feature:*` path (`sessiondetail` → `:feature:session-detail`)
     - One `UNMAPPED <package>` line for each package that matches no prefix.
     - Finally `KOVER-SUMMARY-OK`.
   - `compare <baseline.xml> <final.xml>`:
     - Prints `TOTAL LINE <before>% -> <after>%` and one `MODULE <path> LINE <before>% -> <after>%` line per module.
     - Then prints `KOVER-IMPROVED` and exits 0 when the final total covered/total LINE ratio is strictly greater than the baseline's. Otherwise it prints `KOVER-NOT-IMPROVED` and exits 1.
   - Any missing or unreadable file, or a report with no report-level LINE counter, prints `KOVER-REPORT-MISSING <path>` and exits 1.
   - Wrong arguments print usage and exit 2.
   - Make it executable (`chmod +x`, `git add --chmod=+x`).
