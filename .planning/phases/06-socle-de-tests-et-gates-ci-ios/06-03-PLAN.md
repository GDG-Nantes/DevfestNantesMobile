- **xcresult parsing location:** a script, `scripts/xcresult-assert-tests.sh` (testable locally against real bundles, reused by Phase 11), not inline YAML.

- **Job id and display name unchanged** (`ios-build` / "iOS Build Check"), so any branch-protection required check keeps matching.
- **`actions/upload-artifact@v4`**, matching the `@v4` major-tag convention of checkout/cache in this workflow (RESEARCH A3); if the runner reports v4 as deprecated, bump to the current major in the same step and say so in the SUMMARY.
